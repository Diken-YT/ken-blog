This blog is built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Writing a new post

Add a Markdown file to `src/content/blog/`, fill in the frontmatter, then commit and push. GitHub Actions rebuilds and deploys the site automatically.

```md
---
title: 'My post'
description: 'One-line summary.'
pubDate: 2026-11-10
tags: ['iot']
---
```

Set `draft: true` in the frontmatter to keep a post out of the build.
